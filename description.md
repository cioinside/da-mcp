# Project
Crossplatform Desktop Automation MCP Server (da-mcp)  

## Description
It's provide for AI-agents, such Opencode runing on local\remote PC\Server, opportunity to use local Desktop enviropment for make actions on desktop under Windows, Linux or MacOS
MCP Server: 
- can make screenshot, process it via tesseract OCR for JSON stuctured text reseprenation (windowsm, dialogues, buttons, inputns, radios\checkbox\switcher and etc), send it to agent 
- do actions such input text, move mouse cursor, click controls and others regular\usual user's actions
- run programs
